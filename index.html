About this application

An interactive, fully client-side geospatial platform for exploring drought indicators across Indian districts, built for historical analysis and research communication — not operational monitoring.

Purpose

The explorer links multi-scalar drought indices (SPI, SPEI), land-surface indicators (soil-moisture anomaly, vegetation condition) and administrative geography in a single reproducible workflow: map → district inspection → temporal analysis → event statistics → regional comparison → export. Every number shown is computed in your browser from the loaded dataset; nothing is hard-coded.

How to use

  1. Choose a geographic extent, an indicator and an observation date in the left sidebar.
  2. Inspect districts on the map: hover for a quick readout, click to focus the entire dashboard on that district.
  3. Switch the analysis mode to historical analysis to read event frequency, duration and severity over the selected period.
  4. Open the Analysis Modules tab for indicator-vs-indicator comparison, animated drought evolution, and the download centre.

Current data mode

This build ships a historical research dataset derived with Google Earth Engine from CHIRPS daily precipitation, ERA5-Land monthly potential evaporation and soil moisture, and MODIS MOD13A3 NDVI. SPI, SPEI and soil-moisture anomaly cover January 1981 to December 2025; the Vegetation Condition Index starts in February 2000 because MODIS NDVI begins then (see Methodology). The data layer remains a documented, swappable contract: the static CSVs under data/drought/ and the GeoJSON boundaries can be replaced without code changes (see README).

Technology

HTML5 / CSS3 / vanilla JavaScript (ES6+); Leaflet for cartography; Plotly for scientific charts; Turf.js for client-side geospatial computation; PapaParse for CSV parsing. Vendor libraries are bundled locally with CDN fallbacks. No frameworks, no backend, no database, no API keys.

Methodology

1 · What the indicators measure

SPI (Standardized Precipitation Index; McKee et al., 1993) transforms accumulated precipitation over a chosen window into a probability-based anomaly expressed in standard deviations relative to that calendar month's climatological distribution — negative values indicate precipitation deficit. SPEI (Standardized Precipitation Evapotranspiration Index; Vicente-Serrano et al., 2010) applies the same idea to the climatic water balance (precipitation minus potential evapotranspiration), making it sensitive to both rainfall deficits and atmospheric evaporative demand. The soil-moisture anomaly expresses root-zone-equivalent moisture as a percent departure from its seasonal climatology, and the Vegetation Condition Index (VCI; Kogan, 1995) rescales vegetation greenness between historical stress and optima. SPI/SPEI are dimensionless z-scores; SMA and VCI are percentages.

2 · Accumulation periods and reference period

Accumulation windows of 1, 3, 6 and 12 months are provided for SPI and SPEI: SPI-1/SPEI-1 track immediate meteorological fluctuations; 3-month values approximate a monsoon-season signal; 6-month values align with hydrological storage; 12-month values capture inter-annual drought. Standardization uses the per-calendar-month distribution over the reference period —. A fixed, stated reference period is essential: SPI/SPEI values are only comparable within it.

3 · Standardization and classification

Indicator values are classified with the conventional SPI/SPEI thresholds below. Class edges are inclusive on the dry side (e.g., −2.00 is extreme drought). SMA and VCI use their own documented thresholds because their distributions are bounded percentages — reusing SPI thresholds on them would be invalid.

4 · Spatial aggregation and area computation

Regional means are area-weighted: the mean of district values weighted by each district's precomputed surface area. Affected-area statistics sum the equal-area surfaces of districts whose value falls in a drought class. Areas were precomputed in a Lambert Azimuthal Equal-Area projection centred on India (22.5°N, 79.5°E) — never from degree-coordinate arithmetic. District geometries are served simplified for web performance; statistical areas are computed from the same simplified geometry, so reported areas are internally consistent with the served map.

5 · Drought events

Events are identified by runs analysis (Yevjevich, 1967) on the continuous monthly series: a run of at least 3 consecutive months with the indicator at or below the −1.0 truncation level. Duration = run length in months; severity = cumulative deficit below −1.0 over event months (Σ(−1.0 − x)); mean intensity = severity ÷ duration. Isolated single-month excursions below −1.0 do not constitute events under this definition.

6 · Missing observations

Missing district-months are never imputed, interpolated, or silently treated as normal. Charts show gaps; maps style missing units explicitly as no data; summary statistics use only valid observations (pairwise deletion for comparisons) and always report the valid count; tables show a completeness column and flag sparse rows. KPI cards display N/A rather than derived placeholders when no valid observations exist.

7 · Data lineage in this build

Historical research dataset (Google Earth Engine). Monthly district values were extracted with Earth Engine from UCSB-CHG/CHIRPS/DAILY (precipitation, 0.05°), ECMWF/ERA5_LAND/MONTHLY_AGGR (potential evaporation and 0–100 cm volumetric soil water, 0.1°), and MODIS/061/MOD13A3 (NDVI, ~1 km). Zonal aggregation is area-weighted with ee.Image.pixelArea() on each source's native grid. SPI, SPEI, the soil-moisture anomaly and VCI are computed from those series by the repository's reference Python pipeline (see data-pipeline/). Values are estimates derived from gridded observations and reanalysis, not station measurements; they should be cited with the underlying datasets.

8 · Resolution and limitations

The analysis unit is the administrative district (724 units, 36 states/UTs as supplied); indicator values represent district-level aggregates, not point measurements. Monthly resolution; 540 months (1981-01 to 2025-12) for SPI/SPEI/soil moisture and 311 months (2000-02 to 2025-12) for VCI. Limitations: simplified boundary geometry; gridded source products carry retrieval and representativeness error that is not propagated here; event statistics depend on the stated truncation level and minimum duration; district splits/mergers after the boundary vintage are not reflected. Trend lines (optional, OLS) require ≥ 120 valid observations and are shown with sample size.
