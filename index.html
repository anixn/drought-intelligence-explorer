Hydrological drought propagation

Not available in the current dataset

Streamflow, groundwater, reservoir-storage and runoff observations are not part of the loaded dataset. Propagation from meteorological to hydrological drought therefore cannot be computed here and is not simulated. The soil-moisture anomaly (SMA) is a land-surface reanalysis proxy for the root zone — it is related to, but not a measurement of, hydrological drought.

To enable this section, add a river-discharge dataset (for example GRDC stations or a routed runoff product such as GloFAS reanalysis) as an additional indicator CSV in data/drought/ with the documented schema; the interface will pick it up without code changes.

AAbout the dashboard

Purpose, workspaces, technology and research positioning

An interactive, fully client-side geospatial platform for exploring drought indicators across Indian districts, built for historical analysis and research communication — not operational monitoring.

Developer

Ankit Deshmukh, Ph.D. — Assistant Professor, Department of Civil Engineering, Pandit Deendayal Energy University, India. More research applications and publications: ankitdeshmukh.com.

Workspaces

  1. Overview — where is drought, how severe, how has it changed: map, summary statistics, time series, district ranking, animated drought evolution.
  2. Historical Analysis — frequency, duration, severity, long-term trends (Mann-Kendall / Sen) and recurrence over the analysis period.
  3. Drought Events — the event catalogue and individual events: onset, termination, intensity, recovery, definition sensitivity.
  4. Propagation & Relationships — cross-indicator correlation, optimal lags and district-wise propagation patterns.
  5. Data & Methods — this documentation centre: about, provenance, quality, methodology, glossary and research-ready downloads with metadata.

Current data mode

Technology

HTML5 / CSS3 / vanilla JavaScript (ES6+); Leaflet for cartography; Plotly (cartesian build) for scientific charts; PapaParse for CSV parsing. Vendor libraries are bundled locally with CDN fallbacks. No frameworks, no backend, no database, no API keys.

Positioning and limitations

This is a historical research and communication tool, not an operational drought-warning system: outputs depend on the availability, quality, temporal coverage and methodological assumptions of the underlying datasets, and values are model/reanalysis-based estimates aggregated to administrative districts — not official drought declarations and not the sole basis for operational decisions. See the disclaimer in the application footer and the validation report in section D.

BUser guide

Quick start, workspace map and how to read every output

This dashboard turns district-month drought indicators into maps, statistics, event catalogues and downloadable research outputs. Everything runs in your browser — no account, backend or API key is required.

Quick start

  1. Choose the scope. Set Geographic extent, State / UT, Drought indicator and Analysis period in the dark control panel. These are global: every tab, chart and export follows them. The panel adapts to the active workspace — tab-specific controls (observation date, map display, event filters, indicator pairs) appear in it as you switch tabs.
  2. Pick a date (Overview). The observation date controls the map, KPI cards, severity distribution, district ranking and animation. Use Latest to jump to the most recent observation, or Play to animate the record.
  3. Drill down. Click a district on any map (or choose it in the filters) to focus the whole application on that district. The selection survives tab changes.
  4. Go deeper. Use Historical Analysis for frequency, duration, severity, trends and recurrence; Drought Events for individual episodes; Propagation for cross-indicator relationships.
  5. Export. Tables offer CSV; Data & Methods offers long-format data, statistics, the event catalogue, JSON metadata, boundaries, map PNG and documentation. Every export embeds its analysis settings (section G).

Reading the maps and KPI cards

Maps

Discrete colours follow the indicator’s own class thresholds in metadata.json; the continuous mode interpolates the same palette. Hover for values, click to select a district, and use the legend rail for class ranges and the regional summary. Hatched grey = no data, never zero.

KPI cards

Drought-affected area sums equal-area district surfaces in mild-or-worse classes. Severe + extreme area is the stricter subset. Mean indicator is area-weighted and classified. Districts in drought counts districts at or below the mild threshold. The delta compares with the previous available month.

Uncertainty & significance

Charts always report sample size. The trend test uses a 5% significance level and a 90% Sen confidence interval. Correlations report matched months and a moving-block bootstrap 95% CI that preserves serial dependence. Statistical significance is not proof of causation.

Data caveats

This is a research dataset, not an operational drought declaration. Indicator values depend on the reference climatology, the aggregation method and the underlying model/reanalysis products. Read section C (provenance) and section E (methodology) before citing a result.

Keyboard & navigation

Tabs support ←/→. ? opens this guide from anywhere in the application. Each workspace has a stable URL hash so you can deep-link (#overview, #historical, #events, #propagation, #data, or a section of this page such as #data/e-methods) and refresh without losing the view.

EComplete methodology

Every formula, threshold, assumption and reference applied in this application

Thirteen topics below cover: indicator calculation and standardisation; classification thresholds; spatial aggregation; drought frequency, duration and severity; runs analysis; censoring, intensity, severity and recovery; trend analysis; recurrence; temporal and spatial propagation; bootstrap lags; missing data and uncertainty; and the methodological assumptions. The Markdown download reproduces this methodology with the full reference list.

E1 · Indicator calculation and standardisation (SPI, SPEI, SMA, VCI)

SPI (McKee et al., 1993) standardises accumulated precipitation over 1/3/6/12-month windows against the per-calendar-month climatology of the reference period; SPEI (Vicente-Serrano et al., 2010) applies the same standardization to the climatic water balance (P − PET). The soil-moisture anomaly (SMA) is the percent departure of root-zone-equivalent moisture from its seasonal climatology; the Vegetation Condition Index (VCI; Kogan, 1995) rescales vegetation greenness between historical stress and optimum. Reference period: —. A fixed reference period is essential: SPI/SPEI values are only comparable within it.

Standardization uses the per-calendar-month distribution of the reference period; SPI fits a gamma distribution with a mixed model for zero-rain months and SPEI fits a log-logistic distribution (L-moment estimator as in the reference SPEI package), with Gringorten plotting positions as fallback — see docs/methodology.md §3.1.

E2 · Classification thresholds

Values are classified with the conventional SPI/SPEI thresholds below (class edges inclusive on the dry side, e.g. −2.00 is extreme drought). SMA and VCI use their own bounded-percentage thresholds from the same metadata — reusing SPI thresholds on them would be invalid. These thresholds are identical in every map, chart, table and export of this application.

E3 · Spatial aggregation and area-weighted calculations

Regional means are area-weighted with precomputed district surface areas; affected-area statistics sum equal-area district surfaces. Areas were precomputed in a Lambert Azimuthal Equal-Area projection centred on India (22.5°N, 79.5°E) — never from degree-coordinate arithmetic. Served geometry is simplified; statistical areas come from the same simplified geometry, so reported areas are internally consistent with the map.

E4 · Drought frequency, duration and severity

Drought frequency counts months in which the regional mean is at or below the moderate-drought truncation level (season filters apply to frequency statistics). Duration is the run length of consecutive months below the truncation level; severity is the cumulative deficit below that level over the run. Keep two quantities apart when reading outputs:

  • % of valid months in drought (a district drought-month frequency — how often a district is in drought over the analysis period), and
  • % of area in drought (a spatial share at a given date or averaged over the period — how much of the region's equal-area surface is in drought classes).

The ranking table column Drought-affected area is the area share; Drought months is the temporal frequency. The Event Explorer sensitivity panel re-runs the catalogue with alternative minimum durations or truncation levels; the default definition is always annotated and non-default results are visually separated.

E5 · Drought event identification and runs analysis

Events are identified by runs analysis (Yevjevich, 1967) on the continuous monthly series: a run of at least 3 consecutive months at or below the truncation level (upper bound of the moderate-drought class: −1.0 for SPI/SPEI, −15% for SMA, 30% for VCI). Using the class edge keeps event identification consistent with the classification legend for every indicator. Missing months break runs — they are never interpolated, and no carry-forward is applied. Events touching the record or period edge are flagged censored and reported separately from complete events.

E6 · Event censoring, intensity, cumulative severity and recovery

The per-district catalogue lists onset, termination, duration, maximum intensity (the most negative value), cumulative severity Σ(truncation − value) and mean intensity (severity ÷ duration) of every run. Events that touch the start or end of the available record (or the analysis-period edge) are flagged censored — their true onset or termination may lie outside the observed window — and are excluded from duration/severity ranking while remaining listed.

Recovery counts the months from an event's end to the first value ≥ 0. Note the distinction: the default view treats recovery as a return to neutral conditions (indicator ≥ 0), which is stricter than merely passing back above the drought threshold; — means the record ends first.

E7 · Trend analysis (Mann–Kendall, Sen's slope, Hamed–Rao)

The Historical tab reports the non-parametric Mann-Kendall test (tie-corrected variance) with Sen's slope and its rank-based 90% confidence interval (Gilbert, 1987, §17.3 — the standard two-sided interval for the rank-based estimate). The five-percent significance level applies to the Mann–Kendall test. Monthly drought indices are serially autocorrelated, which inflates naive significance: when significant autocorrelation exists, the Hamed-Rao (1998) variance correction (effective sample size from the significant autocorrelations of the Sen-detrended series) is applied and both the corrected and uncorrected results are shown. Default input is annual area-weighted means (12 valid months averaged per year); monthly granularity is available but strongly autocorrelated.

E8 · Recurrence analysis

Recurrence statistics are empirical and non-parametric on the regional event sequence: mean and median inter-arrival times between event onsets, and severity-exceedance return periods computed as observation years ÷ number of events reaching an empirical severity quantile (Q50/Q75/Q90, type-7 quantile). No distribution is fitted; these point estimates do not quantify their own uncertainty and are labelled indicative only. With few events the estimates carry wide, unquantified uncertainty.

E9 · Temporal propagation and cross-correlation

Cross-indicator relationships use Pearson correlation on matched months only (pairwise deletion; VCI contributes from 2000-02 onward). Correlations run at lags −12…+12 months; the lag convention pairs A[t] with B[t+h], so a positive optimal lag means indicator B responds h months after A. The optimal lag maximises |r| over −12…+12 months with a minimum of 30 matched pairs.

E10 · Optimal lag selection and bootstrap confidence intervals

Confidence intervals use a moving-block bootstrap (95%, 1 000 resamples, block length n1/3 capped at 24, fixed seed 20261103 for reproducibility, percentile method) that preserves serial dependence by resampling blocks jointly. Nominal t-based p-values are shown for reference but treat months as independent.

Selection caveat: the interval is computed at the chosen optimal lag, which is itself selected as the maximum |r| across candidate lags; the reported CI therefore does not account for that cross-lag selection, and intervals at or near the optimum should be read slightly conservatively.

E11 · Spatial propagation and indicator relationships

District-wise optimal lags are mapped from the temporal analysis; the heatmap shows pairwise r at each pair's optimal lag (SPI/SPEI at different accumulation windows are correlated by construction — compare across families for propagation insight). The single-date spatial comparison computes agreement between two indicators over matched dates and matched units only (pairwise deletion): Pearson r, r², RMSE and bias (mean of B−A), with n and the count of excluded districts displayed next to the scatter. The difference view maps B−A in native units on a diverging ramp; when the two families differ (z-score vs %) the contrast mixes units and is labelled as such.

Correlation is never interpreted as causation; streamflow and groundwater propagation sections are explicitly marked unavailable — the dataset contains no such observations and none are simulated.

E12 · Missing data and uncertainty treatment

Missing district-months are never imputed, interpolated, or silently treated as normal. Charts show gaps; maps style missing units as no-data; statistics use valid observations only and always report the valid count; tables show completeness and flag sparse rows (< 50%). KPI cards show N/A rather than derived placeholders. Sample size is always reported: charts show valid counts, tables show completeness, correlations show matched months.

E13 · Methodological assumptions and limitations
  • Event statistics depend on the stated truncation level and minimum duration; different choices will shift counts (the sensitivity panel quantifies this).
  • SMA is a land-surface reanalysis proxy, not observed hydrological drought; no streamflow or groundwater observations exist in this dataset.
  • Correlation and lag statistics are associations, not causal claims; SPI/SPEI at different windows correlate by construction.
  • Areal statistics use the same simplified geometry served for rendering; boundaries are community-maintained 2011-census-demarcation districts, generalised for web delivery, not authoritative for legal boundary determination and do not reflect later reorganisations.
  • Maps' continuous colour scale is a linear interpolation between class-anchor colours (a visual aid); all statistics use the discrete classes.
  • No claim of real-time monitoring: this is a historical and analytical explorer, not an operational warning system.
  • Observed values are model/reanalysis-based estimates; read the underlying dataset documentation in section C before citing a number.

FGlossary and interpretation

What each table shows and how to read every chart and statistic

What each table shows

District-wise ranking (Historical Analysis)

One row per state/UT or district. Mean indicator is the area-weighted mean over the analysis period (season filter applies). Drought-affected area is the average share of area in mild-or-worse drought; for single-district rows it is the share of valid months in drought. Drought months counts months whose regional mean is ≤ the moderate threshold. Rows below 50% completeness are flagged “sparse” and excluded from ranking.

Event catalogue (Drought Events)

One row per drought run. Onset and Termination are the first and last month of the run; Duration is run length; Max intensity is the driest month; Cumulative severity sums the deficit below the truncation level; Recovery is the number of months until the indicator first returns to ≥ 0. Censored events touch the edge of the record and are excluded from duration/severity rankings.

Dataset information (Data & Methods)

The top table documents the build: data mode, region, spatial and temporal resolution, declared period, reference climatology, CRS, area method and provenance. The indicator table lists each indicator’s family, units, accumulation window, valid observations, missing share, availability window and latest observation.

Comparison / agreement (Propagation)

The single-date comparison panel reports, for two indicators at the same month: r (Pearson) and r² across matched districts; RMSE; Bias (B−A) and n (matched). Pairwise deletion is used; nothing is imputed to make the sample look larger.

Data quality (Data & Methods)

A live validation report recomputed in the browser: duplicate district rows, invalid date columns, non-numeric values, unknown district identifiers and completeness within each indicator’s true availability window. Missing values are never imputed.

Reading the charts

Time series

Navy line = area-weighted regional mean (or the selected district). Dotted red lines are drought-class thresholds; gaps are missing months, never interpolated. Optional OLS trend is descriptive only.

Severity distribution

Share of the region’s equal-area surface in each severity class at the selected date. Wet classes are combined; no-data area is reported separately.

Evolution timeline

Percentage of region area in mild-or-worse drought through the full record. Drag the slider to set the dashboard date, or press Play.

Frequency charts

Frequency by year counts months below the truncation level (season filter applies); the district histogram shows the share of valid months in drought across districts — a frequency, not an area share.

Lag correlation

Pearson r at lags −12…+12 months. A positive lag means indicator B responds after A. The diamond marks the largest |r|; the bar is a moving-block bootstrap 95% CI.

Trend panel

Mann–Kendall Z and Sen’s slope with a 90% rank CI. When serial autocorrelation is significant, a Hamed–Rao correction is applied and both results are reported.

Recurrence panel

Empirical inter-arrival times and severity-exceedance return periods. No distribution is fitted; with few events these estimates carry wide, unquantified uncertainty.

Correlation heatmap

Pairwise r at each pair’s optimal lag. SPI/SPEI at different windows are correlated by construction — compare across families for propagation insight.

Sensitivity panel

Event counts when the minimum duration or truncation level is changed. The default methodology is annotated; other points are explicitly alternative scenarios.

Key vocabulary

Indicator units

SPI/SPEI are dimensionless z-scores (population standard deviations from the climatological median, negative = deficit). SMA is a percent departure from the seasonal climatology; VCI is a percent rescaling of NDVI between historical stress and optimum (0–100).

Area-weighted mean

The regional mean indicator value weighting each district by its precomputed equal-area surface — the convention used for every regional statistic in this application.

Drought-threshold recovery vs neutral

Passing back above the mild-drought threshold end the event (runs analysis), while Recovery additionally waits for the indicator to reach ≥ 0 (fully neutral conditions); the difference is visible in longer recoveries.

Confidence intervals

Trend intervals are rank-based 90% bounds on Sen’s slope; lag intervals are 95% moving-block bootstrap percentile bounds that preserve serial dependence.

The downloadable guide in section B (docs/user-guide.md) reproduces this glossary together with the full table-column reference.

GDownloads, reproducibility and citation

All exports are generated client-side from the loaded dataset · every CSV includes a reproducibility metadata header

Every CSV begins with # comment lines recording the indicator, geography, dataset and analysis periods, reference period, methodology version, data mode/seed, source and export timestamp. To reproduce a result externally, keep the exported metadata together with: the indicator id and dataset version (methodology_version), the geographic extent and selected region/district, the observation date (dateIdx) for snapshot statistics, the analysis period and season, the event threshold and minimum duration, and the trend/correlation settings where used.
